# Front Wallet / Panel Institucional

**Rol**: Desarrollo UI/UX, maquetación modular con SASS y consumo de la pasarela de APIs.

## Instrucciones
- Construir vistas responsivas y modernas en React (Vite).
- Utilizar SASS para la estilización.
- Consumir el backend FastAPI mediante Axios para mostrar los datos de forma amigable al usuario.
*Nota*: Aunque la descripción original mencionaba pasarela de pagos, para esta tesis nos enfocaremos en la integración con las APIs de credenciales y SSI.
